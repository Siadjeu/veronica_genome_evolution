# Veronica genome evolution and polyploidy

This repository contains reproducible comparative-genomics analyses used to investigate chromosome evolution, synteny, genome duplication and polyploidy across Veronica species.

## Main analyses

- Genome annotation and quality control
- Phylogenomics
- Chromosome-scale synteny and macrosynteny
- WGDI collinearity and Ks analysis
- Gene- and chromosome-level multisynteny
- Veronica panormitana circular genome overview

## Figure 1B

The circular genome overview of Veronica panormitana was generated from:

Genome FASTA + BRAKER GFF3 + RepeatMasker output + chromosome map

The final tracks include:

- Gene count
- LTR/Gypsy content
- LTR/Copia content
- DNA-transposon content
- GC content

All values were calculated in non-overlapping 1-Mb windows.
