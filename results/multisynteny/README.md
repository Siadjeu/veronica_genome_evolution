# Multisynteny and integrated-evidence result tables

## Files

### `step36X13_integrated_evidence.tsv`

Integrated manuscript checkpoint combining the principal synteny,
multisynteny and Ks evidence.

### `step36X13_macrosynteny_summary.tsv`

Summary of chromosome-scale macrosynteny evidence.

### `step36X13_gene_level_multisynteny.tsv`

Gene-level multisynteny statistics for the primary and additional
comparisons.

### `step36X13_chromosome_consistent_multisynteny.tsv`

Chromosome-consistent multisynteny statistics used to compare diploid and
tetraploid chromosome relationships.

## Interpretation

The independent diploid comparisons provide controls for the background
frequency of multiple chromosome relationships, whereas the diploid–
tetraploid comparisons test whether multisynteny is elevated in the
tetraploid genomes.
