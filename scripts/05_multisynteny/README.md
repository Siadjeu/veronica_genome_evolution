# Quantitative multisynteny and integrated evidence

This directory contains the final scripts used to quantify gene-level and
chromosome-consistent multisynteny in the comparative *Veronica* genome
analysis.

## Purpose

The analyses test whether tetraploid genomes show increased multisyntenic
relationships relative to independent diploid controls.

## Primary comparisons

- PMAJ–VSCU: outgroup–diploid comparison
- VSCU–VANA: diploid–tetraploid comparison
- VSCU–VPER: diploid–tetraploid comparison

## Independent controls

- VSCU–VSER: diploid–diploid comparison
- VSCU–VPAN: diploid–diploid comparison
- VPAN–VPER: independent diploid–tetraploid comparison

## Chromosome-consistent multisynteny

The chromosome-consistent analysis evaluates whether syntenic genes from a
reference chromosome are distributed across multiple target chromosomes.

The conservative top-two support framework was used to distinguish stronger
and weaker multiple-partner chromosome relationships.

## Integrated checkpoint

Step 36X13 consolidates macrosynteny, gene-level multisynteny,
chromosome-consistent multisynteny and Ks evidence into manuscript-oriented
summary tables.

`36X13R` is a metadata/table repair step and does not rerun the biological
analyses.

The repaired current `step36X13_integrated_evidence.tsv` should be used;
pre-36X13R versions are superseded.
